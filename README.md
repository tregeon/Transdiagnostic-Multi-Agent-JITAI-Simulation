# Transdiagnostic-Multi-Agent-JITAI-Simulation
Supplementary material of the simulation study

The overarching intervention design was inspired by Zarski et al. (2025), with several adaptations as part of the present simulation setup regarding the agents, intervention frequency, and structuring of the modules. 

Zarski A-C, Sextl-Plötz T, Schmidt-Hantke J, Hess NS and Buntrock C (2025) Participatory development and proof-of-concept of a dyadic-based, AI-driven, just-in-time adaptive intervention mechanism for preventing anxiety and depressive disorders via app: study protocol for a feasibility study. Front. Public Health 13:1626428. doi: 10.3389/fpubh.2025.1626428
